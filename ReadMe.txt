# Bayesian spatial prediction of livestock tick abundance

This repository contains the data and R code used for the manuscript:

**Bayesian spatial prediction of livestock tick abundance to support surveillance in data-sparse regions**

The analysis evaluates district-level abundance of *Rhipicephalus microplus* and *Hyalomma anatolicum* across Punjab and Khyber Pakhtunkhwa, Pakistan.

## Contents

- Data used for district-level spatial analysis
- Data cleaning and preprocessing scripts
- Environmental variable
- Bayesian spatial BYM2 models fitted using INLA
- District-level prediction and uncertainty mapping
- Leave-one-district-out validation
- Code used to generate manuscript figures and tables

## Software

Analyses were conducted in **R** using packages including `INLA`, `sf`, `terra`, `dplyr`, and `ggplot2`.

## Data availability

The repository contains the analytical data and code required to reproduce the main analyses reported in the manuscript.
